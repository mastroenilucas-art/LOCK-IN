# Coach app

A training app for a coach and their clients.

- **Clients** sign in, see the program you wrote for them, and log every set (weight × reps) and notes. It works with no signal in the gym and syncs when they're back online.
- **You (the coach)** sign in to the same app and get the coach screen: add clients, give each one a program, read their logs, reset passwords, and write or edit programs.
- It runs as an **iPhone app** (TestFlight, later the App Store) and as a **web app** (for Android, or your laptop).

Logins and data live in **Supabase** (free plan). The iPhone app is built in the cloud by **Codemagic**, so you don't need a Mac.

## What's in this folder

| Path | What it is |
|---|---|
| `app.config.json` | **The settings you edit**: app name, Supabase URL and key, help email, invite links |
| `codemagic.yaml` | The iPhone build recipe. Edit the bundle ID lines before the first build |
| `resources/icon.png` | App icon: replace with your own 1024×1024 PNG, no transparency |
| `resources/splash.png`, `splash-dark.png` | Launch screens (2732×2732) |
| `supabase/setup.sql` | Creates the database tables and access rules. Run once in Supabase |
| `supabase/make-me-coach.sql` | Turns your login into the coach account |
| `supabase/functions/manage-clients/index.ts` | Lets the coach add, reset and remove logins, and lets clients delete their account |
| `programs/block-1.json` | The example program (also loaded into the database by setup.sql) |
| `programs/PROGRAM_FORMAT.md` | How programs are written |
| `privacy.html` | Privacy policy page, published with the web version at `/privacy.html` |
| `src/` | The app itself |
| `ios/` | The iPhone project (generated by Capacitor) |
| `netlify.toml` | Settings for the optional web version on Netlify |

## First-time setup (summary)

The full walkthrough is in the setup guide you were sent. In short:

1. **GitHub**: create a private repository and upload everything in this folder.
2. **Supabase**: create a project, run `supabase/setup.sql` in the SQL Editor, turn off new sign-ups, add your own login, run `make-me-coach.sql` with your email, and deploy the `manage-clients` Edge Function (turn off its JWT verification setting).
3. **Connect the app**: put your Project URL and Publishable key in `app.config.json`.
4. **Web version (optional)**: import the repository on Netlify. Sign in and test everything in the browser.
5. **Apple**: join the Apple Developer Program, register a bundle ID, create the app in App Store Connect, create an App Store Connect API key.
6. **Codemagic**: connect the repository and the API key, generate a distribution certificate, create and fetch an App Store profile.
7. **Build**: set your bundle ID in `codemagic.yaml`, then **Start new build** in Codemagic. The build goes to TestFlight.
8. **TestFlight**: fill in Test Information, create the `Clients` group, turn on the public link, and send it to clients.

## Everyday tasks

- **New client**: Coach → Add client. Send them the message it gives you.
- **New program**: Coach → Programs → New program (start from a copy), then **Copy prompt for Claude**, paste Claude's answer, **Save**, and assign it in the client's screen.
- **Forgot password**: Coach → tap the client → Reset password.
- **Change the app** (name, icon, code): commit the change on GitHub, then Start new build in Codemagic.
- **Every 90 days**: TestFlight builds expire. Start a new build in Codemagic before then.

## Run it on a computer (optional, for developers)

```bash
npm install
npm run dev        # http://localhost:5173
```

Needs Node.js 22 or newer.
